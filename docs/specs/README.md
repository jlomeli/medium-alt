# Specs

One markdown file per feature. Specs are canonical intent — the review agent grounds against them, and PRs reference them by path.

Use `_template.md` when starting a new one.

## Roster

- `_template.md` — the template.

_Feature specs will be added as they're written, in the build order defined in [`../architecture.md`](../architecture.md#build-order-v1)._
